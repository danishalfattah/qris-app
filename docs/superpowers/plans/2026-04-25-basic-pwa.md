# Basic PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make QRIS Pay installable as a Progressive Web App on Android and iOS home screens.

**Architecture:** Use Next.js built-in metadata API (`app/manifest.ts`) to serve the web manifest — no extra npm packages needed. Generate placeholder icon SVGs converted to PNG at 192×192, 512×512, and 180×180. Update `app/layout.tsx` metadata to include Apple-specific PWA meta tags.

**Tech Stack:** Next.js 16 App Router, native `Metadata` API, Node.js Canvas-free SVG-based icons via `public/` folder.

### Task 1: Create the Web App Manifest

**Files:**
- Create: `app/manifest.ts`

> Next.js 16 App Router serves a file at `app/manifest.ts` automatically as `/manifest.webmanifest`. No plugin or config change needed.

- [ ] **Step 1: Create `app/manifest.ts`**

```ts
import type { MetadataRoute } from "next";

export default function manifest(): MetadataRoute.Manifest {
  return {
    name: "QRIS Pay",
    short_name: "QRIS Pay",
    description: "Scan & Pay dengan QRIS - Pembayaran digital cepat dan aman",
    start_url: "/",
    display: "standalone",
    background_color: "#B71C1C",
    theme_color: "#B71C1C",
    orientation: "portrait",
    icons: [
      {
        src: "/icons/icon-192.png",
        sizes: "192x192",
        type: "image/png",
        purpose: "maskable",
      },
      {
        src: "/icons/icon-512.png",
        sizes: "512x512",
        type: "image/png",
        purpose: "any",
      },
    ],
  };
}
```

- [ ] **Step 2: Verify manifest is served**

Start the dev server:
```bash
npm run dev
```
Then open in browser: `http://localhost:3000/manifest.webmanifest`

Expected: JSON response with `name: "QRIS Pay"`, `display: "standalone"`, etc.

- [ ] **Step 3: Commit**

```bash
git add app/manifest.ts
git commit -m "feat: add PWA web app manifest"
```

### Task 2: Generate Icon Assets

**Files:**
- Create: `public/icons/icon-192.png`
- Create: `public/icons/icon-512.png`
- Create: `public/icons/apple-touch-icon.png`

> We generate icons using a small Node.js script that writes SVG-sourced PNGs. The SVG uses the brand red `#B71C1C` background and a white "Q" letter. The script uses only the built-in `canvas` npm package — if canvas is not available, use a plain SVG fallback approach described at the end.

- [ ] **Step 1: Create the icon generation script**

Create a temporary file `scripts/generate-icons.mjs`:

```js
// Run with: node scripts/generate-icons.mjs
import { createCanvas } from "canvas";
import { writeFileSync, mkdirSync } from "fs";

mkdirSync("public/icons", { recursive: true });

function drawIcon(size) {
  const canvas = createCanvas(size, size);
  const ctx = canvas.getContext("2d");

  // Background
  ctx.fillStyle = "#B71C1C";
  ctx.beginPath();
  ctx.roundRect(0, 0, size, size, size * 0.18);
  ctx.fill();

  // Letter Q
  ctx.fillStyle = "#FFFFFF";
  ctx.font = `bold ${size * 0.55}px sans-serif`;
  ctx.textAlign = "center";
  ctx.textBaseline = "middle";
  ctx.fillText("Q", size / 2, size / 2);

  return canvas.toBuffer("image/png");
}

writeFileSync("public/icons/icon-192.png", drawIcon(192));
writeFileSync("public/icons/icon-512.png", drawIcon(512));
writeFileSync("public/icons/apple-touch-icon.png", drawIcon(180));

console.log("Icons generated in public/icons/");
```

- [ ] **Step 2: Install `canvas` package temporarily and run the script**

```bash
npm install canvas --save-dev
node scripts/generate-icons.mjs
```

Expected output:
```
Icons generated in public/icons/
```

Verify files were created:
```bash
ls public/icons/
```
Expected: `apple-touch-icon.png  icon-192.png  icon-512.png`

> **If `canvas` fails to install** (it requires native build tools): Use the SVG fallback below instead.
>
> **SVG fallback** — create the three files manually as SVG and rename to `.png` only if the browser accepts them. Better: use an online converter (e.g. svgtopng.com) with this SVG:
> ```svg
> <svg xmlns="http://www.w3.org/2000/svg" width="512" height="512" viewBox="0 0 512 512">
>   <rect width="512" height="512" rx="92" fill="#B71C1C"/>
>   <text x="256" y="340" font-size="300" font-family="sans-serif" font-weight="bold"
>         text-anchor="middle" fill="white">Q</text>
> </svg>
> ```
> Save as `icon-512.png`, then resize to 192×192 and save as `icon-192.png`, and 180×180 as `apple-touch-icon.png`.

- [ ] **Step 3: Uninstall canvas (dev-only cleanup)**

```bash
npm uninstall canvas
```

- [ ] **Step 4: Commit icons**

```bash
git add public/icons/
git rm scripts/generate-icons.mjs
git commit -m "feat: add PWA icon assets (192, 512, 180px)"
```

### Task 3: Update layout.tsx with Apple PWA Meta Tags

**Files:**
- Modify: `app/layout.tsx`

> The existing `metadata` export already has `title` and `description`. We extend it to add Apple PWA meta tags. The `viewport` export with `themeColor` is already correct and doesn't need changing.

- [ ] **Step 1: Update the `metadata` export in `app/layout.tsx`**

Replace the existing `metadata` export:

```ts
export const metadata: Metadata = {
  title: "QRIS Pay - Mobile Payment",
  description: "Scan & Pay dengan QRIS - Pembayaran digital cepat dan aman",
};
```

With:

```ts
export const metadata: Metadata = {
  title: "QRIS Pay - Mobile Payment",
  description: "Scan & Pay dengan QRIS - Pembayaran digital cepat dan aman",
  manifest: "/manifest.webmanifest",
  appleWebApp: {
    capable: true,
    statusBarStyle: "black-translucent",
    title: "QRIS Pay",
  },
  icons: {
    apple: "/icons/apple-touch-icon.png",
  },
};
```

- [ ] **Step 2: Verify the generated HTML**

Run dev server (`npm run dev`) and view page source at `http://localhost:3000`. Check `<head>` contains:

```html
<link rel="manifest" href="/manifest.webmanifest"/>
<meta name="apple-mobile-web-app-capable" content="yes"/>
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent"/>
<meta name="apple-mobile-web-app-title" content="QRIS Pay"/>
<link rel="apple-touch-icon" href="/icons/apple-touch-icon.png"/>
```

- [ ] **Step 3: Commit**

```bash
git add app/layout.tsx
git commit -m "feat: add Apple PWA meta tags and manifest link to layout"
```

### Task 4: End-to-End PWA Verification

> Use Chrome DevTools Lighthouse to confirm the app passes PWA installability checks.

- [ ] **Step 1: Build and start production server**

```bash
npm run build
npm run start
```

- [ ] **Step 2: Run Lighthouse PWA audit**

1. Open `http://localhost:3000` in Chrome
2. Open DevTools (F12) → "Lighthouse" tab
3. Select "Progressive Web App" category only → click "Analyze page load"

Expected results:
- "Installable" section: all checks green
- "PWA Optimized" section: mostly green (some warnings about HTTPS are expected on localhost)

Key checks that must pass:
- ✓ Web app manifest exists
- ✓ Icons are valid (192px and 512px present)
- ✓ `display: standalone` is set
- ✓ `theme_color` matches meta theme-color

- [ ] **Step 3: Test "Add to Home Screen" on mobile (optional but recommended)**

On an Android phone connected to the same network:
1. Open Chrome → navigate to `http://<your-local-ip>:3000`
2. Tap the three-dot menu → "Add to Home screen"
3. Confirm the icon and name appear correctly

```bash
git add -A
git commit -m "chore: PWA verification and final tweaks"
```
