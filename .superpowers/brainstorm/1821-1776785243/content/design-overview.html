2. lib/api.ts — Fungsi API

Fungsi yang akan ada di lib/api.ts
login(username, password) → POST /api/auth/login
register(username, password, initial_balance) → POST /api/auth/register
inquiryByPayload(qris_payload, token) → GET /api/qris/inquiry/{payload}
inquiryByImage(imageFile, token) → POST /api/qris/inquiry/image
createPayment(inquiry_id, amount, pincode, token) → POST /api/qris/payment
getTransactionStatus(transaction_id, token) → GET /api/qris/status/{id}

3. Perubahan Flow Scan & Bayar

Flow Baru di app/scan/result/page.tsx
① Scan QR (kamera) → decode payload → inquiryByPayload(payload)
② Atau: upload gambar → inquiryByImage(file)
③ Tampilkan: merchant_name, city, terminal_id, fixed_amount (atau input jika 0)
④ User input PIN 6 digit → createPayment(inquiry_id, amount, pincode)
⑤ Response 202 → dapat transaction_id → mulai polling
⑥ Polling getTransactionStatus(transaction_id) tiap 2 detik
⑦ Status SUCCESS/FAILED → tampilkan result, update balance di context

4. Perubahan Auth Context

lib/auth.tsx — State yang disimpan
token: string // JWT untuk semua request
account_id: string // dari login/register response
balance: number // di-update setelah transaksi sukses
updateBalance(newBalance) // dipanggil dari scan/result setelah polling

5. Halaman Baru: /register

Form Register
• Field: username (alphanumeric), password (min 8), initial_balance (≥ 0)
• Pada sukses: langsung login otomatis (token sudah ada di response)
• Redirect ke home setelah register
• Link "Sudah punya akun? Login" → /login
